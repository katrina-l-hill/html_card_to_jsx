# Converting HTML Profile Card to JSX

This assignment provides hands-on practice converting standard HTML markup into valid JSX syntax, as used in React components. 

# Features
- Reusable Component: Accepts user data via props for name, email, and photo.
- JSX Syntax Compliance: Demonstrates best practices like `className`, tag closing, and React-friendly formatting.
- Expo Compatibility: Works smoothly in an Expo-managed React Native project.

# Installation
- Clone the repo:
  - git clone `https://github.com/katrina-l-hill/html_card_to_jsx`
  - cd profile-card
  - npx expo start
